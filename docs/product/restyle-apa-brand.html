Putting the APA brand on the Company OS

The OS still wears the Edge8 scaffold it was built from. The public site at austpayroll.com.au has a settled identity: navy, steel, gold, Montserrat. This maps that identity onto the OS as a token swap, not a redesign.

Approved and implemented · 1 Sep 2026

The problem

  • The sign-in card, browser tab, and admin sidebar all say "8 Edges".
  • public/logo.png is the Edge8 wordmark. The nav, footer, and the ROI PDF all pull from it.
  • The palette is Edge8's bright blue #287BE8 and mint #6FF2C1; the typeface is Manrope.

Proposed restyles

The OS reads nearly everything from canonical tokens in app/globals.css, and the admin re-roots onto those in app/admin/admin.css. Layout, spacing, the dense 13px data layer, radii, and elevation rules all stay exactly as they are.

1 · Colour tokens

TokenNow (Edge8)Proposed (APA)
--color-primary-blue#287BE8to#465778 brand navy
--color-primary-blue-hover#1D6AD4to#394A66 darkened navy
--color-accent-mint#6FF2C1to#E6B73D gold
--color-primary-dark#101014to#2A3550 navy ink
--color-text-body#797C82to#4A5160 cool grey
--tint-deep#D4DAE4to#C9D2E0 steel-tinted

The focus ring, blue glow, and info-status derivatives follow automatically or get re-derived from navy.

2 · Typography

Replace Manrope with Montserrat for display and Source Sans Pro for body, self-hosted woff2 exactly as Manrope is today. Both ship Vietnamese subsets, which the OS needs for people and client names. Source Sans Pro is distributed as "Source Sans 3" now; same design.

Montserrat runs wider than Manrope, so expect minor reflow in the sidebar and table headers. A cheaper fallback if that worries anyone: keep Manrope for the dense admin data layer and use Montserrat only for --font-display, so public pages read as APA while admin tables stay metric-identical.

3 · Admin chrome

  • Sidebar from near-black to deep navy #2A3550, matching how the live site uses its navy bands. Muted sidebar text shifts to steel #A0AEC2.
  • Active nav item and section accents take gold where mint is used today.
  • Chart ramp becomes navy, gold, steel, navy ink, grey. Same five-step structure.

One conflict to resolve: the current warning badge pair is gold-toned. With gold promoted to the accent, warnings should shift clearly amber-orange so a warning never reads as a highlight.

4 · Naming and marks

  • "8 Edges" becomes "APA Company OS" in the sidebar header, sign-in card, and title template (AdminSidebar.tsx, app/admin/(dashboard)/layout.tsx).
  • public/logo.png and logo-white.png replaced with the APA lockup. Re-check the nav, footer, and the ROI PDF route after the swap.

5 · Buttons

The OS pill radius already matches the live site's buttons, so shape stays. Fill changes: gold with navy text for public-facing calls-to-action, navy for primary actions inside the admin, where gold would shout on every table row.
