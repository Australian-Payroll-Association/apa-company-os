01 · What this does

Two moving parts, both invisible once they work

The Human Token Tracker measures two things per repo: AI tokens (your Claude usage) and human tokens (your active hours). Both are read from the transcripts Claude Code already writes on your machine — nothing new to log by hand.

  • Setup turns on the live capture: a SessionEnd hook that delivers each session to the tracker automatically, forever, through your own gh login. Do it once per computer.
  • Backfill is a one-time catch-up for the work you did before setup. It reads the last 30 days of local transcripts and delivers them the same way. Safe to re-run — the server de-duplicates every record.

No secrets, ever. Neither job needs a database key, an ingest secret, or a token from an admin. Everything is delivered to a Git branch using the GitHub access you already have. If you can push to a repo, you can deliver telemetry.

Records are keyed by telemetry/<owner>/<repo>/<your-login>/, so the setup hook and the backfill land in the same place and are attributed to the same person. Attribution is by your GitHub login and git email — so those must match your team-member record (the setup checklist verifies this).

Your repo must be registered first. The dashboard only ingests telemetry for repos it knows. Edge8's active repos already are. If yours is brand new and shows nothing after a backfill, ask an admin to register it (or add a registrations/<owner>__<repo>.json entry) — then re-run the backfill.

03 · Add tracking to a computer

Five checks, one fix, done once per machine

The tracker ships a doctor that inspects every gate and prints ✓ / ⚠ / ✗ with the fix for each. Run it from inside any repo you work in — it is read-only and touches nothing:

Run the doctor
bash scripts/telemetry-doctor.sh

It verifies the six things capture needs. Here is what each one is and how to satisfy it:

The one fix almost everyone needs: make gh's token readable

The SessionEnd hook runs in a background context that can't read the OS credential store (macOS Keychain / Windows Wincred), so deliveries silently pile up in an outbox and never arrive. Re-login telling gh to use file storage:

gh auth logout --hostname github.com
gh auth login --hostname github.com --git-protocol https --insecure-storage
# choose: GitHub.com  →  HTTPS  →  "Login with a web browser"  (paste the code)

--insecure-storage writes your own repo-scoped token to ~/.config/gh/hosts.yml (file perms 600 — only you can read it). It's the trade-off that lets the background hook deliver hands-free. Revoke or rotate anytime with gh auth logout. Prefer the keychain? Then run the flush yourself periodically instead — see Troubleshooting.

Confirm your identity will attribute correctly

Work is credited by your GitHub login and git email. Make the email match your team-member record (the doctor flags a mismatch):

git config --global user.email "you@edge8.co"   # the address on your team-member record

Flush anything already captured, then verify

# send sessions that were captured but stuck (redirect stdin or it waits for input)
bash ~/.claude/hooks/session-telemetry-end < /dev/null

# should trend toward 0 — an empty outbox means delivery is working
ls -1 ~/.claude/.il-telemetry/outbox/ | wc -l

From here, every session you run is delivered automatically. You never touch this again on this machine.

04 · Backfill the last 30 days

One script, run once, from inside the repo

Setup only captures work from now on. To recover the last month, run the backfill from inside the repo you want to catch up. It reads your local transcripts, computes AI tokens and active hours, and delivers them to the same telemetry branch — dry-run by default, so you always see the numbers before anything is written.

Save the script (§05) somewhere handy, then:
cd ~/code-projects/edge8-web            # the repo you want to backfill

python3 backfill-human-tokens.py                    # DRY RUN — prints the totals, writes nothing
python3 backfill-human-tokens.py --commit           # deliver: last 30 days
python3 backfill-human-tokens.py --days 14 --commit  # a shorter window
python3 backfill-human-tokens.py --tz +07:00 --commit  # bucket days in your timezone

A dry run prints exactly what it found before you commit to anything:

repo:     talentedgeai/edge8-web
you:      dhajdu <dave@edge8.co>
window:   last 30 days   hours rule: active + 30min/block
found:    86 sessions, 154,870,143 Claude tokens, 96.6 human hours over 17 days
DRY RUN — would add to talentedgeai/human-token-tracker#telemetry:
    telemetry/talentedgeai/edge8-web/dhajdu/2026-07.backfill.jsonl
    telemetry/talentedgeai/edge8-web/dhajdu/2026-08.backfill.jsonl

How hours are counted — and the one machine where it matters

Human hours come from your transcript timestamps, pooled per day and split into activity blocks wherever there's a gap over 5 minutes. The default adds a 30-minute credit per block (the canonical team-hours rule — it matches ongoing live capture, so the 30-day seam is smooth).

On a machine that runs autonomous agents 24/7 (e.g. the Mac Mini), every unattended agent burst mints its own block and pockets 30 free minutes, inflating the hours. On those machines only, add --active-only to count measured active time with no per-block credit. On a normal laptop, keep the default.

Re-running is safe

The backfill writes to a distinct *.backfill.jsonl filename that can never overwrite the live hook's files, and the server de-duplicates every record by session id (AI) and by member-day-hour (human). Run it twice, run it after setup — nothing double-counts.

05 · The script

backfill-human-tokens.py

Self-contained, standard library only. Copy it into the repo (or anywhere on your PATH) and run it as shown above. It needs git and gh on your PATH and delivers only through your own GitHub access — no secrets.

#!/usr/bin/env python3
"""
backfill-human-tokens.py — one-time catch-up of recent Claude Code work into the
Human Token Tracker.

It reads your LOCAL Claude Code transcripts (~/.claude/projects), turns them into
telemetry records, and writes them onto this repo's `telemetry` branch — which the
tracker ingests server-side. No secrets, no database access: it delivers through
your own `gh`, exactly like the live SessionEnd hook does. Re-running is safe; the
server de-duplicates every record.

Run it from INSIDE the repo you want to backfill:

    python3 backfill-human-tokens.py                 # last 30 days, DRY RUN (writes nothing)
    python3 backfill-human-tokens.py --commit        # write + push to the telemetry branch
    python3 backfill-human-tokens.py --days 14 --commit
    python3 backfill-human-tokens.py --active-only --commit   # agent-heavy machine (see the post)
"""
import argparse, glob, json, os, subprocess, sys, tempfile
from collections import defaultdict
from datetime import datetime, timezone, timedelta

GAP_S = 5 * 60          # activity blocks split on a 5-minute gap (team-hours.py §2.3)
SESSION_CREDIT_S = 1800 # 30 min credited per block, unless --active-only

# All contributor telemetry is collected on ONE branch of the tracker repo, keyed by
# telemetry/<owner>/<repo>/<login>/. The server ingests from there. Override with the
# HTT_REPO env var if your org forks the tracker.
TRACKER_REPO = os.environ.get("HTT_REPO", "talentedgeai/human-token-tracker")
TELEMETRY_BRANCH = "telemetry"


def sh(cmd, cwd=None):
    return subprocess.run(cmd, cwd=cwd, capture_output=True, text=True, check=True).stdout.strip()


def repo_identity():
    root = sh(["git", "rev-parse", "--show-toplevel"])
    url = sh(["git", "remote", "get-url", "origin"])
    # git@github.com:owner/repo.git  or  https://github.com/owner/repo(.git)
    tail = url.split("github.com", 1)[1].lstrip(":/").removesuffix(".git")
    owner, repo = tail.split("/")[:2]
    login = sh(["gh", "api", "user", "--jq", ".login"])
    email = sh(["git", "config", "user.email"])
    return root, owner, repo, login, email


def transcript_dirs(repo):
    base = os.path.expanduser("~/.claude/projects")
    out = []
    for d in glob.glob(os.path.join(base, "*")):
        if not os.path.isdir(d):
            continue
        core = os.path.basename(d).split("--claude-worktrees-")[0]  # keep worktrees, drop suffix
        if core.endswith("-" + repo):                              # excludes <repo>-demo etc.
            out.append(d)
    return out


def parse_ts(t):
    try:
        return datetime.fromisoformat(t.replace("Z", "+00:00"))
    except Exception:
        return None


def active_seconds(stamps):
    stamps.sort()
    active, run_start, prev = 0.0, stamps[0], stamps[0]
    for ts in stamps[1:]:
        if (ts - prev).total_seconds() > GAP_S:
            active += (prev - run_start).total_seconds()
            run_start = ts
        prev = ts
    active += (prev - run_start).total_seconds()
    return active, stamps  # active time only; caller adds block credit if wanted


def blocks_and_active(stamps):
    stamps.sort()
    blocks, active, run_start, prev = 1, 0.0, stamps[0], stamps[0]
    for ts in stamps[1:]:
        if (ts - prev).total_seconds() > GAP_S:
            active += (prev - run_start).total_seconds()
            blocks += 1
            run_start = ts
        prev = ts
    active += (prev - run_start).total_seconds()
    return blocks, active


def build_records(repo, owner, login, email, days, active_only, tz):
    since = datetime.now(timezone.utc) - timedelta(days=days)
    by_month = defaultdict(list)
    day_stamps = defaultdict(list)
    seen = set()
    n_sessions = tok_total = 0

    for d in sorted(transcript_dirs(repo)):
        for f in sorted(glob.glob(os.path.join(d, "*.jsonl"))):
            sid = os.path.splitext(os.path.basename(f))[0]
            if sid in seen:
                continue
            seen.add(sid)
            tokens, first, last, branch, stamps = 0, None, None, None, []
            for line in open(f, encoding="utf-8", errors="replace"):
                try:
                    o = json.loads(line)
                except Exception:
                    continue
                ts = parse_ts(o.get("timestamp") or "")
                if ts and ts >= since:
                    stamps.append(ts)
                    day_stamps[ts.astimezone(tz).strftime("%Y-%m-%d")].append(ts)
                    first = ts if first is None or ts < first else first
                    last = ts if last is None or ts > last else last
                if o.get("gitBranch"):
                    branch = o["gitBranch"]
                u = (o.get("message") or {}).get("usage")
                if u and ts and ts >= since:
                    tokens += ((u.get("input_tokens") or 0)
                               + (u.get("output_tokens") or 0)
                               + (u.get("cache_creation_input_tokens") or 0))
            if tokens <= 0 or first is None:
                continue
            n_sessions += 1
            tok_total += tokens
            _, mins = blocks_and_active(stamps)
            by_month[first.astimezone(tz).strftime("%Y-%m")].append({
                "record_type": "claude", "session_id": sid, "claude_tokens": tokens,
                "active_minutes": max(1, round(mins / 60)),
                "started_at": first.isoformat(), "ended_at": last.isoformat(),
                "repo_full_name": f"{owner}/{repo}", "session_branch": branch,
                "author_email": email, "github_login": login,
                "client_slug": owner, "project_slug": repo,
            })

    hours_total = 0.0
    for day, lst in sorted(day_stamps.items()):
        blocks, active = blocks_and_active(lst)
        secs = active if active_only else active + blocks * SESSION_CREDIT_S
        hours = round(secs / 3600, 2)
        if hours < 0.05:
            continue
        hours_total += hours
        by_month[day[:7]].append({
            "record_type": "human", "occurred_on": day, "resolved_hours": hours,
            "source": "claude-jsonl-backfill", "commit_hours": [],
            "author_email": email, "github_login": login,
            "repo_full_name": f"{owner}/{repo}", "started_at": f"{day}T00:00:00+00:00",
            "client_slug": owner, "project_slug": repo,
        })
    return by_month, n_sessions, tok_total, round(hours_total, 1), len(day_stamps)


def write_files(base, owner, repo, login, by_month):
    rel = []
    for month, recs in sorted(by_month.items()):
        p = os.path.join(base, "telemetry", owner, repo, login, f"{month}.backfill.jsonl")
        os.makedirs(os.path.dirname(p), exist_ok=True)
        with open(p, "w") as fh:
            for r in recs:
                fh.write(json.dumps(r) + "\n")
        rel.append(os.path.relpath(p, base))
    return rel


def write_and_push(owner, repo, login, by_month, commit):
    """Shallow-clone the tracker's telemetry branch with your own gh, add the
    backfill files, and push. A separate '*.backfill.jsonl' filename can never clobber
    the live hook's files, and the server de-duplicates every record on ingest."""
    if not commit:
        rel = write_files(tempfile.mkdtemp(prefix="htt-dry-"), owner, repo, login, by_month)
        print("DRY RUN — would add to", f"{TRACKER_REPO}#{TELEMETRY_BRANCH}:")
        for r in rel:
            print("   ", r)
        return
    tmp = tempfile.mkdtemp(prefix="htt-telemetry-")
    clone = os.path.join(tmp, "tracker")
    try:
        sh(["gh", "repo", "clone", TRACKER_REPO, clone, "--",
            "--branch", TELEMETRY_BRANCH, "--single-branch", "--depth", "1"])
        rel = write_files(clone, owner, repo, login, by_month)
        for r in rel:
            sh(["git", "add", r], cwd=clone)
        sh(["git", "commit", "-m",
            f"telemetry: backfill {login} on {owner}/{repo} from local transcripts"], cwd=clone)
        sh(["git", "push", "origin", TELEMETRY_BRANCH], cwd=clone)
        print(f"Pushed to {TRACKER_REPO}#{TELEMETRY_BRANCH}. Your tokens appear after the next ingest.")
    finally:
        subprocess.run(["rm", "-rf", tmp])


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--days", type=int, default=30)
    ap.add_argument("--active-only", action="store_true",
                    help="active time only, no 30-min block credit (agent-heavy machines)")
    ap.add_argument("--tz", default="+00:00", help="local day offset, e.g. +07:00")
    ap.add_argument("--commit", action="store_true", help="actually write + push (default: dry run)")
    a = ap.parse_args()

    sign = -1 if a.tz.startswith("-") else 1
    hh, mm = (a.tz.lstrip("+-").split(":") + ["0"])[:2]
    tz = timezone(timedelta(hours=sign * int(hh), minutes=sign * int(mm)))

    _root, owner, repo, login, email = repo_identity()
    by_month, n_sessions, tokens, hours, days_covered = build_records(
        repo, owner, login, email, a.days, a.active_only, tz)

    print(f"repo:     {owner}/{repo}")
    print(f"you:      {login} <{email}>")
    print(f"window:   last {a.days} days   hours rule: "
          f"{'active-only' if a.active_only else 'active + 30min/block'}")
    print(f"found:    {n_sessions} sessions, {tokens:,} Claude tokens, "
          f"{hours} human hours over {days_covered} days")
    if not by_month:
        print("Nothing to backfill (no sessions for this repo in the window).")
        return
    write_and_push(owner, repo, login, by_month, a.commit)
    if not a.commit:
        print("\nThis was a DRY RUN. Re-run with --commit to write and push.")


if __name__ == "__main__":
    main()

06 · Troubleshooting

SymptomCause & fix
Dashboard shows 0 / "—" for your workCaptured but not delivered. Run the doctor; almost always the gh keychain fix in §03.
Backfill says "Nothing to backfill"No sessions for this repo in the window. Check you're inside the right repo, and that transcripts exist: ls ~/.claude/projects | grep <repo>.
Older than ~30 days is missingClaude Code auto-deletes transcripts after ~30 days (cleanupPeriodDays). Purged history can't be recovered from transcripts — raise that setting to keep more going forward.
Numbers land but aren't attributed to youYour git email or GitHub login doesn't match your team-member record. Fix the email (§03) and ask an admin to confirm your record.
gh repo clone fails in the backfillgh isn't authenticated, or you lack access to the tracker repo. Run gh auth status; ask an admin for read/write on the tracker repo.
Prefer not to use --insecure-storageKeep the keychain and flush manually now and then: PYTHONPATH="$HOME/.claude/hooks" python3.12 -m il_telemetry.flush.

Delivered ≠ visible instantly. Your records appear on the dashboard after the next server ingest (runs on a schedule). If you need it now, ask an admin to trigger the ingest.
