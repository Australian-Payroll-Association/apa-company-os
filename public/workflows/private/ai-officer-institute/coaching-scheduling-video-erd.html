Locked decisions (grilling rounds 1–2, 2026-08-07)

One generic live_event table. A coaching session IS an event row — no bespoke coaching table. Micro-session and cert-class events attach via optional FKs; CHECK event_surface_shape ties event_type to the matching FK.
Signup is one row with a lifecycle — signed_up_at / attended_at / cancelled_at; partial UNIQUE on live rows. Walk-ins get an attended-only row. Archive attendee list = attended_at IS NOT NULL.
Cert-class events: designed, not built. One enum label + one nullable FK (dashed). Zero endpoints, zero UI.
Topics are body-only, visible to the group, with a NULLABLE event FK — "move to next week" = re-point the FK. Max 8 accepted per event is an app rule, never a constraint.
key_learnings + resources live on live_event — so micro-sessions and future cert classes inherit them for free.
Homework hangs on micro_session (assignment_instructions/_rubric); submission gets exactly-one-of (activity_id, micro_session_id). Existing grading pipeline reused via a resolver branch.
Polished-replaces-Zoom = video.superseded_by_video_id. Display rule everywhere: hide superseded. Nothing is deleted — the transcript source survives.
Watch tracking = one upsert row per (user, video). Fed by FE IFrame-Player heartbeats — our own build; YouTube's Data/Analytics APIs cannot attribute minutes to a logged-in learner. Completion threshold is an app rule.
category is a curated table (seed: AI Officer · AI Engineer · Micro-sessions) with join tables per surface. tags text[] stays a free-flowing folksonomy on video. Curation truth, not placement truth — admins link new videos.
One track at a time = soft pointer app_user.current_certification_id. Business students pick AI Officer, STEM pick AI Engineer — switchable, no entitlement state machine.
Coaching recordings are video rows via video_on_live_event — never a bare URL (the recording_url pattern #1100 is retiring). They stay status='draft' → library-hidden unless deliberately published.
House conventions: uuidv7 PKs, text + CHECK (never native enums — the material_type lesson), trg_touch timestamps, RLS enabled with no policies (service-role only, like video).

Assumptions pending Dave

Micro-session cert credit. Dave says micro-sessions count toward certification; ERD §6.5 deliberately gates on course final-projects only. The schema stores both readings — flipping is a computation change, no migration — but it must be an explicit call, not a side effect.
Coaching earns no credit — assumed, never stated. If wrong, event_signup.attended_at already carries the fact; only the computation changes.
"Replace" resolved as display-rule (keep both videos, hide superseded) — Khoa's call; confirm with Dave in passing since deletion would destroy the transcript that key-learnings generation needs.

Impacted code seams

Grading resolver branches on which submission FK is set — submission_resolver.py in the live V2 pipeline is the seam.
Library query grows three reads: category join, hide-superseded filter, per-user watch stats.
New FE↔BE seam: player wrapper posts progress heartbeats → video_watch upsert endpoint. This is what makes "watched the recording ⇒ credit" enforceable.
"All live sessions we run" — Dave's analytics ask — becomes one query over live_event, no UNION.
micro_session.recording_url retirement (#1100) — coaching never grows the anti-pattern; recordings ride placements from day one.
