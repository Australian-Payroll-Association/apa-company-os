Voice & content

Direct, confident, lightly provocative. Motivational, never corny.

Vocabulary

Missions not lessons · tracks not courses · cohort not class · challenges · AI Buddy (never “chatbot”) · “the 50/50 era”

“You” not “we”. Short sentences. Punchy fragments. Concrete numbers: “95% of companies see no ROI from AI.”

Casing & numerics

✓ Sentence case everywhere: “Sign up for Thursday”, “Go to Challenge →”

✓ UPPERCASE wide-tracked eyebrows: Your programs

✓ All numerics in mono: 44% · 8/10 · 0 day streak · 1,240 xp

✗ Emoji in prose or headlines — accents only (🔥 ⚡ 🤖 in chips/buttons)

Color

Deep navy backbone. Royal blue is the single CTA color. Magenta rarest. Mint is the signal. No purple, no pastel gradients. Big numbers navy, labels gray — color only where it carries meaning.

Shadows & motion

Two shadow levels, always navy-tinted — never pure black. Motion is subtle and functional: no bounces, no scale-ups, no rotations.

Rules that make screens read as one product

PatternRule
LayoutAsymmetric grid: main column + 340px sidebar. One dark navy card per screen for the key CTA.
NumbersNavy mono numbers, gray labels. Color appears only in track bars, pills and the one CTA.
Progress6px full-radius bar, black/5 track, mono value label beside it.
Sticky toolbarsPill tab switcher / filter chips on blurred paper (bg paper/90 + backdrop-blur), bordered top+bottom.
AccordionsCard shell + summary row (name, stats, bar, chevron rotate 180°); groups inside as light bordered boxes.
Navy heroFlat navy + subtle radial glows only (blue top-right 45%, magenta bottom-left 40%, mint top-center 10%). The ONLY place gradients appear.
Empty / lockedDashed borders, muted text, a Locked tag — explain the path forward, never dead-end.
