Statement of Work 2 · Chapter Event System

Eventbrite events, in OneEO, automatically

Chapters keep running events on Eventbrite. A bridge copies each chapter's upcoming events into OneEO, where members see them in one place and click Register to go to Eventbrite. This is a full-time engagement — roughly one person for two months — covering the build, a five-chapter beta, and the client coordination and communications that rolling chapters out actually takes. Progress is tracked in a shared rollout tracker alongside the feedback tool, so everything is visible in one place.

01

Build the bridge

~90 h · one-time

Built once, tested end-to-end on Hivebrite's sandbox before any chapter uses it. Events in OneEO look and behave like today's chapter events.

What's included

  • Read events from Eventbrite — each connected chapter's upcoming events.
  • Create & update events in OneEO — same rules as today's legacy feed.
  • A Register button — links to Eventbrite; sign-up and payment stay there.
  • Kept in step, automatically — every 30 min; no duplicates.
  • Right chapter, right audience — each event tagged to its chapter.
  • Logging & alerts — a broken connection is flagged within the hour.
  • Tested & handed over — sandbox-tested; runbook + onboarding checklist.

03

Rollout coordination & shared tracker

~180 h

Getting chapters live is mostly coordination, not code — and it needs a single place to see where every chapter stands. This is the difference between a build and a working rollout.

What's included

  • Chapter onboarding communications — reaching contacts, explaining the ask, chasing Eventbrite access.
  • Scheduling & sequencing — lining chapters up, connecting them in order, confirming each is live.
  • Hands-on support at go-live — walking chapters through it and fixing what real data surfaces.
  • Shared rollout tracker — one view of every chapter's connection status, built to also hold the feedback tool.

Assumptions, needs & risks

Assumptions

  • List-only: registration stays on Eventbrite.
  • Chapter events only; upcoming (next 12 months), no backfill.
  • Each chapter already has its OneEO group and category.
  • Runs on Edge8's existing platform — no new infrastructure.

What we need

  • Five beta chapters, with a contact at each.
  • Hivebrite sandbox API credentials.
  • A test Eventbrite account with a few events.
  • One decision: Members only, or also Spouse/LP and Adult Children?

Risks

  • Hivebrite login change (15 Feb 2027) — we build on the new method from day one.
  • Duplicates — for connected chapters, events come from Eventbrite; matched by title + date.
  • Accuracy — ±30%; the beta gives firm numbers.
